# LensChain - Photography Portfolio Management System

A blockchain platform for photographers to showcase work, develop skills, and earn rewards for creative achievements.

## Features
- Photography session tracking and rewards
- Photographer skill progression system
- Camera equipment investment bonuses
- Photography workshop hosting
- Photo contest participation

## Smart Contract Functions
- Track photography sessions and shoots
- Reward creative photography achievements
- Invest in camera equipment for returns
- Host photography workshops and classes
- Participate in photography competitions

## Usage
Empowers photographers through verified portfolio management and skill development rewards.
